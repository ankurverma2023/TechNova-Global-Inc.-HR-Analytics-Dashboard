# TechNova-Global-Inc.-HR-Analytics-Dashboard
Power BI HR analytics report covering workforce headcount, compensation equity, talent risk, and attrition drivers for a fictional 75,000-employee global technology company.

## 📊 Pages Overview

### 1. Executive Overview
- Headcount by Department
- Gender Distribution
- Performance Ratings
- Global Workforce Map

### 2. Workforce Deep-Dive
- Avg Salary by Department
- Salary vs Performance
- Training Hours Analysis
- Engagement vs Satisfaction

### 3. Attrition & Risk
- Attrition Rate by Department
- Exit Reasons
- Attrition Trends
- Flight Risk Analysis

## 📈 Key KPIs
- Total Employees: 75,000  
- Attrition Rate: 12.59%  
- Voluntary Attrition: 2.91%  
- Avg Salary: $116K  
- Avg Tenure: 7.6 years  
- Years Since Promotion: 5.08  

## 🛠 Tools Used
- Power BI  
- DAX  
- Power Query  
- Data Modeling  
- Row-Level Security (RLS)  

## 🔐 Features
- Interactive slicers (Region, Department, Employment Type)  
- Dynamic KPIs & visuals  
- Region-based RLS implementation  

## 📂 Files Included
- `.pbix` dashboard file  
- Dataset (CSV)  
- Dashboard screenshots  

## 🚀 Key Insight
Low voluntary attrition indicates structural issues like delayed promotions rather than employee dissatisfaction.
